# TERN — Electric Kettle

**A Modern Product Landing Page**

TERN is a frontend web development project featuring a product landing page for an electric kettle concept. The project focuses on presenting a consumer product through a structured, visually refined, and user-oriented web interface.

## Project Overview

The TERN landing page is designed to communicate the product's identity and present its visual features through a dedicated digital experience.

The development emphasizes clean markup, maintainable styling, visual consistency, and responsive web design.

## Live Preview

**Website:** [View Live Website]( https://sushanttandan.github.io/tern-electric-kettle/)

## Technologies Used

- **HTML5** — Semantic document structure and content organization.
- **CSS3** — Layout, styling, visual presentation, and responsive design.

## Key Objectives

- Develop a polished product-oriented landing page.
- Establish a consistent visual identity.
- Implement structured and maintainable HTML and CSS.
- Apply modern CSS layout techniques.
- Provide an adaptable interface across different screen sizes.
